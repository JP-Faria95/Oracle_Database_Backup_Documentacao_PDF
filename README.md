# Oracle Database 21c - Backup e Recuperação

## 📖 Sobre o projeto

Este repositório reúne estudos, scripts e documentações desenvolvidos durante o aprendizado de **Backup e Recuperação no Oracle Database 21c**.

O objetivo é documentar, de forma prática, as principais técnicas de nível iniciante utilizadas para garantir a disponibilidade e recuperação de bancos de dados Oracle em situações de falha.

Todo o conteúdo foi testado em ambiente de laboratório e organizado para servir como material de consultas e estudos.

---

# Objetivos

* Aprender os conceitos de Backup e Recovery do Oracle.
* Documentar procedimentos passo a passo.
* Disponibilizar um material de referência para futuras consultas.

---

# Conteúdo

Atualmente o projeto aborda:

* Configuração do ARCHIVELOG
* Configuração da Fast Recovery Area (FRA)
* RMAN (Recovery Manager)
* Backup Full
* Recovery
* Data Pump (EXPDP/IMPDP)
* Configuração de DIRECTORY
* Gerenciamento de arquivos de backup
* Testes de recuperação

---

# Tecnologias utilizadas

* Oracle Database 21c
* Oracle SQL*Plus
* Oracle Recovery Manager (RMAN)
* Oracle Data Pump (EXPDP/IMPDP)
* Windows
